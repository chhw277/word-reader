# 今日单词短文

把不背单词里刚背完的单词，交给 AI 写成几篇短文，在真实语境里再读一遍。

## 用法

1. 在不背单词里导出「近日已学」PDF。
2. 打开网页，点「导入不背单词 PDF」选中文件。
3. 第一次使用时，在「API 设置」里填 API Key（默认 DeepSeek，模型 `deepseek-flash`）。
4. 点「生成短文」。每篇先写初稿，再自动精修一遍。

## 功能

- 单词黄色高亮，点击看释义；作文常用句式用虚线标出，文末附用法说明
- 每篇附中文翻译、本文单词表、小测验
- 历史文章保存在浏览器里
- 深色模式

## 隐私

这是一个纯静态网页，没有服务器。API Key、设置和历史文章只保存在你自己的浏览器里，请求直接从浏览器发给模型服务商。不要把 Key 写进代码里提交到仓库。
