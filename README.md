# 今日单词短文

把不背单词里刚背完的单词，交给 AI 写成几篇短文，在真实语境里再读一遍。

## 用法

1. 第一次使用时，在「API 设置」里填 API Key（默认 DeepSeek，模型 `deepseek-flash`）。只用填一次。
2. 每天在不背单词里导出「近日已学」PDF。也支持 Word（.docx）、TXT、Excel、CSV 和图片。其他文件也可以：别的单词表直接读取；英文文章、课本会让 AI 挑出值得背的词；扫描件会让 AI 看图识别（需要支持看图的模型，DeepSeek 默认的 deepseek-flash 就可以）。
3. 打开网页，点「选择今天的 PDF」或右上角的按钮选中文件，也可以把 PDF 拖进页面。选好就自动开始写，每篇先写初稿，再自动精修一遍。

## 功能

- 单词黄色高亮，点击看释义；作文常用句式用虚线标出，文末附用法说明
- 每个新词在文中至少出现两次；按遗忘曲线（1、2、4、7、15、30 天）把旧词混进新文章复习，用青色标出
- 复习词在小测验里也有题：答对才进入下一个间隔，答错第二天重来，没做题的第二天再出现
- 默认每篇 8 个新词、2 个复习词，文章长度按词数自动放宽，避免硬塞
- 每天最多写 3 篇（可调），优先写最新学的词；当天没写到的词进入复习计划，之后按遗忘曲线混进文章
- 「一千零一夜」模式（默认）：每晚一篇约 1600 词的连载故事，用 40 个最新学的词。外层讲故事的人和听众固定，每晚讲一个新故事，中间有一段人物辩论（考研阅读式议论文），结尾留悬念。文末有 5 道考研式阅读理解题（主旨、细节、推断、态度、词义）和单词题
- 每篇附中文翻译、本文单词表、小测验
- 历史文章保存在浏览器里
- 单词本：查看每个词哪天学的、出现几次、答题情况和下次复习时间，可以按「今天该复习」「最近答错」筛选；支持导出备份和导入恢复（备份里不含 API Key），换设备时用
- 深色模式

## 隐私

这是一个纯静态网页，没有服务器。API Key、设置和历史文章只保存在你自己的浏览器里，请求直接从浏览器发给模型服务商。不要把 Key 写进代码里提交到仓库。
